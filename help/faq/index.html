1. 当前版本已不再维护

解决办法：
参照安装文档安装最新版本。

2. 网络链接

日志提示:
network request error: 不知道这样的主机。 (os error 11001)

解决办法：
保持网络链接，本 App 需要定时从时钟池同步内部时钟。

3. DNS 污染类型错误/证书类错误

这个系列的错误也属于 DNS 污染类型错误，导致系统将 huan-app.github.io 解析到错误的 IP。

日志提示:

  • error sending request for url (https://huan-app.github.io/v0.1.1)
  • No connection could be made because the target machine actively refused it. (os error 10061)
  • invalid peer certificate: UnknownIssuer

解决办法：
(a) 检查 C:/Windows/System32/drivers/etc/hosts 文件是否包含 huan-app.github.io 相关的记录。如果有直接删除即可。
(b) 检查 Windows 系统的 DNS 配置，是否使用了不可用的配置。
